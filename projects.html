Deformable Medical Image Registration with Learned Proximal Networks Python

Deformable image registration finds a smooth spatial transformation aligning one image to another — the basis for comparing brain scans across patients or tracking anatomical change over time. The problem is ill-posed: many different deformations align the images equally well, so a regularizer is needed to select a plausible one. Classical solvers like ANTs impose this with a fixed smoothness assumption, typically a Gaussian. This project replaces that hand-designed prior with a Learned Proximal Network — a neural network trained on displacement fields, architecturally constrained so it provably behaves as a proximal operator — plugged into a plug-and-play ADMM solver. The aim is a regularizer that reflects the actual statistics of anatomical deformation rather than a generic smoothness assumption, while retaining the convergence guarantees of classical optimization. Evaluation uses 2D phantoms and 3D brain MRI (NIREP), benchmarked against ANTs/SyN and PIRATE, and measures not just image similarity but the accuracy of the recovered deformation field itself and whether it remains diffeomorphic.

Learned Proximal Networks for High-Dimensional Hamilton–Jacobi PDEs Python

Build on Fang, Buchanan and Sulam (ICLR 2024). The method learns a convex potential whose gradient is the proximal operator, then recovers the prior either by inverting that gradient per query or by fitting a second network — the latter matching a fully tuned inversion baseline without ever inverting.
